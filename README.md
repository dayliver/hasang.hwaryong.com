# 성정하상바울로성당 미사 슬라이드

비공식 웹 앱 — 미사 식순·성가 번호·OSMD 악보·블랙·이미지를 슬라이드로 구성하고, 미사 시간별로 저장해 투사합니다.

## 개발

```bash
npm install
npm run dev
```

## 화면

| 경로 | 역할 |
|------|------|
| `/` | 미사 목록 |
| `/edit/:id` | 슬라이드 순서·방식 편집 |
| `/present/:id` | 전체 화면 슬라이드쇼 (←→ / Space) |

## 슬라이드 방식

- **이미지** — 인트로 등 전체 화면
- **블랙** — 침묵·전환용 검정 화면
- **성가 악보** — OpenSheetMusicDisplay (MusicXML), 다크/라이트
- **성가 번호 / 기도문 / 식순 / 표지**

## 떼제 미사 패턴

`인트로 이미지 → 블랙 → 미사곡(OSMD) → 블랙 → …`

샘플: `/edit/taize-demo` · `/present/taize-demo`

악보 파일은 편집 화면에서 **파일 선택 / 끌어다 놓기**로 올리면 됩니다.
브라우저(이 컴퓨터)에 저장되며, MusicXML이 없으면 이미지 악보도 올릴 수 있습니다.
샘플 데모 곡은 `public/scores/*.musicxml` 경로를 그대로 씁니다.
